# This is the README.md file for the **github-final-project**

A calculator that calculates simple interest given principal, annual rate of interest and time period in years.

Input:
   p, principal amount
   t, time period in years
   r, annual rate of interest
Output
   simple interest = p*t*r

   
Simple Interest Calculator

📌 Description
.This project is a Simple Interest Calculator that computes the simple interest based on user-provided values. It is designed as a beginner-friendly program to demonstrate basic programming concepts such as input, arithmetic operations, and output formatting.

.Simple Interest is calculated using the formula:
.Simple Interest = (Principal × Rate × Time) / 100


🚀 Features
->Accepts principal amount, rate of interest, and time period
->Calculates simple interest accurately
->Easy to understand and modify
->Suitable for beginners and educational purposes.
